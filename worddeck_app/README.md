# WordDeck 每日词卡

这是一个**纯前端、本地优先**的背单词应用。无需数据库和账号，打开网页即可使用。

## 已包含

- 内置 631 条初始词库：来自你上传的 8 份英语复盘 Word 文档。
- 每日随机新词：可选 50 / 100 / 200 / 300 / 500。
- 四选一：显示英文，从 4 个中文释义中选择。
- 轮次学习：第一轮全部完成后可自动进入第二轮，之后可继续第三轮、第四轮……；也可以手动开始下一轮或重开当前轮。
- SRS 间隔复习：默认 1、2、4、7、14、30 天，可自行修改。
- 错题本：答错自动进入，同一练习中可稍后再次出现。
- 收藏、暂停词条、搜索和来源筛选。
- 浏览器英文朗读（Speech Synthesis）。
- CSV / TSV / TXT / JSON 导入；完整进度备份与恢复。
- 响应式布局：电脑和手机均可使用。
- PWA：通过 HTTPS 或 localhost 打开时，可安装到手机/电脑桌面并离线使用。

## 最快使用方法

### 电脑
直接双击 `index.html`。学习进度保存在当前浏览器中。

### 手机
推荐把整个文件夹放到任意静态网页托管（GitHub Pages、Netlify、Cloudflare Pages 等）。如果电脑和手机在同一 Wi-Fi，也可以在本文件夹打开终端运行：

```bash
python -m http.server 8080
```

然后手机访问 `http://电脑局域网IP:8080`。

> 电脑浏览器与手机浏览器的本地数据彼此独立。可在“设置 → 导出完整备份”，再到另一台设备“导入完整备份”。

## 自己导入单词

推荐 CSV：

```csv
english,chinese,example,note,tags
abate,减弱；缓和,The storm began to abate.,常用于强度下降,考研
in light of,鉴于；考虑到,"In light of the evidence, ...",固定搭配,短语
```

也支持 TSV 或竖线文本：

```text
abate | 减弱；缓和 | The storm began to abate. | 常用于强度下降 | 考研
```

JSON 格式：

```json
[
  {"english":"abate","chinese":"减弱；缓和","example":"The storm began to abate.","note":"","tags":"考研"}
]
```

## 学习规则

- **轮次**：答对才算完成当前轮；答错不会计入本轮完成。
- **复习**：每次答对会提高 SRS 阶段并安排下一次复习；答错会降低阶段并设为当天到期。
- **第二轮**：完成整套词库的第一轮后自动进入第二轮（可在设置关闭自动进入）。SRS 记忆阶段不会因为换轮而清空。
